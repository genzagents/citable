Privacy policy

Last updated 27 October 2026. citable is published by genzagents, London, United Kingdom. Contact: github.com/genzagents/citable/issues.

The plugin, CLI, MCP server and GitHub Action

These run on your own machine or in your own GitHub Actions runner. They send nothing to genzagents and contain no analytics or telemetry. To check a site they make ordinary HTTP requests to that site only: robots.txt, the homepage, llms.txt, the sitemap, and the homepage again with each AI crawler user agent. Nothing is stored except what you ask for, such as a report file or a GitHub issue in your own repository.

The optional citable track command sends the prompts you choose to the AI provider whose API key or local Claude Code install you supply (Anthropic, OpenAI or Perplexity), under that provider’s own terms. genzagents never sees those keys, prompts or answers.

The hosted paid tier

If you subscribe to citable hosted, we hold your GitHub username, what you put in your Hosted watch issue (the sites, the prompts and brand name you list) and the reports we generate for you. Payments are taken by GitHub Sponsors; we never see your card details or email address. Your issue and the reports posted on it are public on GitHub, and GitHub emails you each one. We use this data only to run the checks and post the results. We keep it while your subscription is active and delete it within 30 days of cancellation, or sooner if you ask through the contact link above. We do not sell or share it with anyone else.

Your rights

You can ask for a copy of your data, a correction, or deletion at any time through the contact link above. If you are in the UK or EU you may also complain to your data protection authority (in the UK, the ICO).
